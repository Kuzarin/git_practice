# Library Management System

A simple library management system written in Python.

## Features

- Add books
- Display all books
- Search for books
- Borrow books
- Return books

## Technologies

- Python 3

## Project Structure

- `book.py` — Book class
- `library.py` — Library class
- `main.py` — Main program

## How to Run

1. Clone the repository.
2. Open the project directory.
3. Run the program:

```bash
python3 main.py
